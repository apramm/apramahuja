## what it does

Plans trips that stay within a budget and favour lower-impact travel options.

## how it works

A Flask backend builds prompts from the user's input and sends them to Llama 3 on Amazon
Bedrock, using few-shot examples to shape the responses. The frontend and backend were deployed
on an AWS EC2 instance.
